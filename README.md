# Agentic URL Shortener — Java 21

[![Java 21 CI](https://github.com/walid-physics/agentic-url-shortener-java/actions/workflows/main.yml/badge.svg)](https://github.com/walid-physics/agentic-url-shortener-java/actions/workflows/main.yml)

A governed agentic software-engineering system and URL-shortener service built with Java 21 and Spring Boot.

The solution demonstrates:

- REST APIs for URL creation, redirection, expiration, deletion, and analytics
- Stateful workflow orchestration using an explicit dependency graph
- Parallel task execution and synchronization
- Human approval gates
- Bounded retries, rollback, replanning, and safe-stop controls
- Workflow event auditing and decision records
- AI-assisted requirements, architecture, planning, testing, security, and review agents
- Automated testing through GitHub Actions
